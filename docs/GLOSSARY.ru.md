# Глоссарий OpenEMIS — ключевые термины для управления школой и MCP

Этот глоссарий определяет основные термины, с которыми вы сталкиваетесь при использовании OpenEMIS или сервера openemis-mcp. Каждая запись называет термин, объясняет, как он используется в системе управления школой OpenEMIS, и ссылается на соответствующее руководство или ресурс.

---

### OpenEMIS

OpenEMIS (Open Education Management Information System — Открытая система управления образовательными данными) — это бесплатная, открытая школьная информационная система, разработанная ЮНЕСКО и KORDIT. Она управляет учениками, персоналом, посещаемостью, оценками, инфраструктурой, питанием, стипендиями и отчётностью на уровне министерства в детских садах, школах, средних профессиональных и высших учебных заведениях.

### OpenEMIS Core

OpenEMIS Core — серверное приложение, обеспечивающее работу REST API по адресу `/api/v5/{resource}`. Данный MCP-сервер ориентирован на Core 5.10.0, который открывает 675 ресурсов и 3 355 эндпоинтов.

### MCP (Model Context Protocol)

MCP — открытый протокол от Anthropic, позволяющий AI-ассистентам (Claude, Cursor, Codex, Cline) вызывать внешние инструменты структурированным образом. openemis-mcp — это MCP-сервер, предоставляющий 6 инструментов для запроса данных OpenEMIS. Инструкции по установке — в [README](../README.md).

### Школьная информационная система (SMIS)

Школьная информационная система (SMIS или EMIS) — программное обеспечение, централизующее административные данные для учебных заведений: зачисление, посещаемость учеников, оценки, персонал, инфраструктуру и отчётность. OpenEMIS — это поддерживаемая ЮНЕСКО SMIS, используемая в нескольких странах.

### Управление образованием

Управление образованием — административный надзор за образовательными учреждениями: учёт учеников, персонала, ресурсов и результатов. OpenEMIS поддерживает управление образованием на уровне школы, района и министерства.

### Посещаемость учеников

В OpenEMIS посещаемость учеников регистрируется по исключению: хранятся только события отсутствия и опоздания. Ученик без строки в отмеченный день считается присутствующим. Данные хранятся в `student-attendance-marked-records` и `institution-class-attendance-records`. См. [руководство по просмотру посещаемости](playbooks/view-latest-attendance.md).

### Посещаемость персонала

Посещаемость персонала отслеживается через `institution-staff-attendances`. Записи об отпусках хранятся в `institution-staff-leave`. См. [руководство по просмотру профиля сотрудника](playbooks/view-staff-profile.md).

### Риски учеников / система раннего предупреждения

OpenEMIS рассчитывает составной балл риска для каждого ученика за каждый академический период на основе настраиваемых критериев (посещаемость, успеваемость, поведение). Баллы хранятся в `institution-student-risks`. См. [руководство по просмотру рисков учеников](playbooks/view-student-risks.md).

### Инцидент поведения

Инцидент поведения — зарегистрированная запись о поведении ученика, хранящаяся в `student-behaviours`. Инциденты имеют категорию, классификацию, дату и опциональное вложение. Отображаются в [руководстве по панели ученика](playbooks/student-dashboard.md).

### Рабочий процесс / очередь приёма / очередь зачисления

OpenEMIS использует настраиваемый плагин рабочих процессов для управления многоэтапными цепочками согласования — приём, зачисление, переводы персонала и другие. Каждый рабочий процесс имеет модели, шаги, статусы, переходы и ответственных по ролям.

### Учреждение (детский сад, школа, вуз)

Учреждение в OpenEMIS — любое образовательное заведение, зарегистрированное в системе: детский сад, начальная или средняя школа, среднее профессиональное учебное заведение, технический колледж или университет. Каждое учреждение имеет уникальный `institution_id`. См. [руководство по просмотру профиля учреждения](playbooks/view-institution-profile.md).

### Академический период

Академический период — определённый временной промежуток (год, семестр, четверть), которым ограничены большинство данных в OpenEMIS: посещаемость, оценки, зачисление и баллы рисков. Большинство ресурсов API требуют `academic_period_id` как обязательный фильтр.

### Образовательный уровень (ступень)

Образовательный уровень (например, 1-й класс, 9-й класс, 12-й год) — ступень внутри образовательной программы. OpenEMIS хранит уровни в `education-grades`. Предлагаемые учреждением уровни записаны в `institution-grades`.

### Класс / секция

Класс в OpenEMIS — именованная группа учеников, прикреплённая к классному руководителю в рамках учреждения и академического периода, хранящаяся в `institution-classes`. Он имеет уровень обучения, список учеников и расписание. См. [руководство по просмотру профиля класса](playbooks/view-class-profile.md).

### Оценка за экзамен / табель успеваемости

Оценки за экзамены хранятся в `assessment-item-results` — одна строка на ученика на элемент оценивания. Табель успеваемости объединяет оценки по предметам за период. См. [руководство по просмотру оценок](playbooks/view-student-marks.md) и [руководство по отчёту по классу](playbooks/view-class-report.md).

### Предмет / учебная программа

Предмет (математика, английский, естествознание и т.д.) определяется в `education-subjects` на системном уровне и связывается с классом через `institution-class-subjects`. Учебная программа — полный набор предметов, преподаваемых на данном уровне обучения.

### Руководство (плейбук)

В openemis-mcp руководство — это пошаговая инструкция, объясняющая AI-агенту, как ответить на конкретный вопрос о школьном управлении, используя последовательность вызовов `openemis_get`. Руководства хранятся в `data/playbooks.json` и извлекаются инструментом `openemis_get_playbook`. Документация в формате Markdown находится в [docs/playbooks/](playbooks/).

### Ресурс (в терминах MCP)

В openemis-mcp ресурс — любой API-эндпоинт, доступный через `GET /api/v5/{resource}`. OpenEMIS Core 5.10.0 предоставляет 675 ресурсов в таких доменах, как Учреждение, Ученик, Персонал, Оценивание, Посещаемость и Рабочий процесс. Инструмент `openemis_get` получает любой ресурс по имени. См. [Справочник по ресурсам](resources.md).
